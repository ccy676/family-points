# 土拨鼠宠物素材规范

> 给美工团队的交付清单。按下方规格准备文件后，我（开发侧）可以把 CSS 占位图替换为真实素材。

---

## 一、必交：成长阶段形象（5 张）

土拨鼠有 5 个成长阶段，每个阶段需要 1 张主形象图。

| 阶段 key | 阶段名称 | 建议文件名 | 说明 |
|---|---|---|---|
| `baby` | 土拨鼠宝宝 | `baby.png` | 最小、最圆、最可爱 |
| `child` | 幼年土拨鼠 | `child.png` | 比 baby 大一点，开始有明显特征 |
| `teen` | 少年土拨鼠 | `teen.png` | 青少年体型 |
| `adult` | 成年土拨鼠 | `adult.png` | 成年体型，毛发更蓬松 |
| `king` | 土拨鼠大王 | `king.png` | 最大、最威风，可戴皇冠/披风 |

### 技术规格
- **格式**：PNG（透明背景）或 GIF（透明背景、循环动画）
- **尺寸**：建议 200×200 px，最大不超过 300×300 px
- **画布比例**：1:1（正方形）
- **透明背景**：必须，因为宠物要站在场景草地上
- **色彩风格**：暖棕色系，与现有海洋/草地主题协调
- **姿态**：正面站立或 3/4 侧面，面向玩家，重心在画面下方，留出头顶空间（皇冠会额外叠加）

### 如果只做静态图
- 5 张 PNG 就够了，观赏技能可以用 CSS 位移动画配合。

### 如果要做 GIF 动画
- 每个阶段可以是一张循环 GIF，包含待机呼吸/眨眼/摇摆。
- 也可以按技能拆分为多个 GIF（见下文）。

---

## 二、可选：观赏技能动作（5 个）

每个阶段解锁一个技能。如果想让技能更生动，可以为每个技能单独提供动画。

| 技能 key | 技能名称 | 建议文件名 | 动作建议 |
|---|---|---|---|
| `peek` | 探头 | `skill-peek.gif` | 从下方快速探出头再缩回 |
| `wag` | 摇尾巴 | `skill-wag.gif` | 快速摇尾巴 + 开心表情 |
| `spin` | 转圈圈 | `skill-spin.gif` | 原地旋转 1-2 圈 |
| `jump` | 上蹿下跳 | `skill-jump.gif` | 连续跳两下 |
| `dance` | 跳舞 | `skill-dance.gif` | 左右摇摆 + 挥手 |

### 技术规格
- **格式**：GIF（透明背景）
- **尺寸**：200×200 px 或 250×250 px
- **时长**：1-1.5 秒，播放一次即可（代码会控制播放）
- **透明背景**：必须

## 三、可选：喂食道具与特效

| 用途 | 建议文件名 | 说明 |
|---|---|---|
| 饲料袋 | `feed-bag.png` | 一袋花生/谷物，50×50 px 左右 |
| 升级特效 | `level-up.png` / `level-up.gif` | 进化时的光效/星星/彩带，可透明背景 |
| 爱心/开心符号 | `heart.png` | 喂食后冒出的爱心，30×30 px |

## 四、可选：宠物页背景

目前宠物页场景是 CSS 渐变草地。如果想更逼真，可以提供一张背景图。

| 用途 | 建议文件名 | 说明 |
|---|---|---|
| 宠物页背景 | `pet-scene.png` | 草地 + 天空 + 远处山丘，480×240 px |
| 洞穴入口 | `burrow.png` | 土拨鼠脚下的洞口，120×40 px |

### 背景建议
- 风格：卡通、温馨、与海绵宝宝/海洋主题不冲突
- 色调：蓝天、绿地、暖光
- 不要画宠物本身，只画环境
